다운로드·재신청 전 확인해 주세요

다운로드 전송이 시작되면 사용 완료로 처리되고 서버의 음원이 삭제됩니다. 취소하거나 연결이 끊겨도 사용 완료될 수 있으니 안정적인 연결에서 저장해 주세요.

재신청하면 기존 다운로드 권한과 저장 파일을 종료하고 같은 음악을 다시 준비합니다. 새 음악을 생성하지 않으며, 이 페이지 주소는 그대로 유지됩니다.
